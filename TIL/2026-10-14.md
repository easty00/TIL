# STEP 1. 웹 서비스 이해

## 1강 : 기본 개념
---

### 웹의 흐름
```
사용자 > 프론트엔드 > 백엔드서버 > 데이터베이스
```

1. 사용자(Client) : 웹 서비스 이용자
    - 사용자에게는 프론트엔드까지만 보여준다.
    - 백엔드와 직접적인 대화는 할 수 없다
    - 대신 프론트엔드를 통해 교류하게 된다.

2. 프론트엔드(FE)
    - UI(User Interface) : 사용자가 백엔드와 교류하는 수단. 중간에서의 매개체
    - 데이터를 예쁘게 꾸며줌 (UI/UX)

3. 백엔드(BE)
    - 프론트로부터 전달되는 결과를 받아 처리함
    - 특정한 업무를 처리하는 개발. 논리적인 사고를 구현해내는 것

4. 데이터베이스(DBA, DataBase Architecture)
    - 데이터를 관리하는 물리적인 영역
    - 웹은 영속성을 갖는 데이터를 사용자의 ui에 뿌리는 것. 이를 위해 데이터를 가지는 곳이 필요함
    - 사용자가 브라우저(프론트엔드)를 통해 갖기를 원하는 정보의 저장고
    - 신입으로 DBA를 하는건 어려움.

- 웹은 요청과 응답으로 이루어져있는 흐름
    - Request
        - 사용자가 원하는 정보를 얻기위해 프론트엔드의 ui를 통해 일어나는 이벤트, 요청하는 모든 행위
    - Response
        - 사용자의 요청이 DB에 도달하면, DB 에서 사용자에게 요청에 대한 응답이 돌아옴

- FE, BE, DBA 세가지 모두 하는 개발자를 풀스택 개발자라고 함.
