## HTML 이란? 
    - 웹페이지의 뼈대와 구조를 담당하는 차세대 웹 표준 마크업 언어

- element : div ul 등..
 
```
<!DOCTYPE html> HTML5 의 선언문

    <meta charset="UTF-8">

    <!-- 화면에 보여질 콘텐츠가 들어가는 자리 -->
```

### HTML 의 역사
- 스티브잡스 : 웹 세계에 큰 파장을 일으킨 인물. 아이폰의 창시자로, 핸드폰에 웹을 이식함

    - 대표적으로 네이버의 웹사이트는 화면을 줄이면 아래에 스크롤이나오며 웹사이트는 움직이지 않는다.
    - 하지만 네이버의 모바일 버전은 반응형으로 나옴. 아이폰이 나오면서 출시

    - 최초의 마크업 미디어 회사에서 만들고 어도비에서 인수

- 웹에서 3D 기술은 그냥 돌아가지 않음.

#### 시맨틱태그(Semantic Tag)
    - 이름만 보고도 어떤 역할과 위치인지 의미를 직관적으로 알 수 있게 만든 HTML5 요소

![alt text](image-3.png)
- 웹 표준을 지켜야 하는 이유
    - 크로스 브라우징(Cross Browsing): 크롬, 엣지, 사파리, 파이어폭스 등 어떤 운영체제나 브라우저를 사용하더라도 동일하게 보이고 정상 작동하도록 보장
    - 웹 접근성 향상: 장애인이나 고령자를 포함한 모든 사용자가 기기나 브라우저에 구애받지 않고 정보에 접근할 수 있도록 돕습니다
        - 구글의 검색엔진에 걸리기 위해선 웹 표준을 지켜야 함.
        - 검색에는 alt? 태그를 많이 봄. 사회적 약자들도 사용할 수 있어야 한다. 
    - 유지보수 및 확장성: 구조(HTML)와 표현(CSS)을 분리하여 코드가 간결해지고, 향후 수정이나 확장 작업이 쉬워집니다
    - 검색 엔진 최적화(SEO): 의미에 맞는 시맨틱 태그(header, nav, section, footer 등)를 사용하여 검색 엔진이 웹페이지의 정보를 정확히 이해하게 만듭니다

- footer, adress  등의 태그가 빠르게 찾아질수록 검색의 상위엔진으로 올라올 수 있다. 
- 태그는 정의를 다르게 해도 동작이 달라지진 않는다. 프론트엔드 개발자라면 이 태그 요소들이 컴포넌트 설계로 연결된다.
- 내 머릿속에 웹 표준과 시맨틱 태그 구조에 대해 숙지하는것이 유리하다.

## 같은 웹 화면을 만들어도 직군마다 생각하는 것이 다르다
| 직군 | 먼저 생각하는 것 |
| --- | --- |
| 디자이너 | 보기 좋게, 정보를 정돈하기 |
| 기획자 | 데이터부터 화면까지 전체가 쓰기 편하게 |
| 프론트엔드 | 사용자가 보는 화면, 컴포넌트 |
| 백엔드 | 어떤 데이터를 빠르게 줄지. 데이터 플로우, 분산처리 |
| 풀 스택 | 위의 전부 |

- UI : 사용자가 직접 보고 누르는 화면 요소 (버튼,입력창,메뉴)
- UX : 사용자가 서비스를 쓰면서 느끼는 전체 경험
    - 헷갈리나? 쓰기 편한가? 빠른가?



    - ux : 백엔드와 프론트엔드, 개발자가 생각하는 것이 다르다.
        - 백엔드 : 빠르게 데이터를 표현하고 분산처리, 데이터의 플로우를 많이 생각. 데이터를 어떤걸 줘야하는지 많이 물어봄
        - 프론트엔드 : 화면을 봄.
        - 기획자 : 데이터부터 프론트까지 어떻게 나와야하는지를 알아야 함
        - 풀스택 : 다 해야함

## 자바 스크립트 (JavaScript)
    - 웹 페이지의 동적 기능을 구현하기 위해 사용되는 프로그래밍 언어
- 현재에 오며 꽤 중요한 언어가 되었다.
- 원론을 벗어나지 않고 돌을 깎아만든 형태

```
• 기본 개념: HTML(웹 페이지의 구조), CSS(웹 페이지의 디자인)와 함께 웹을 구성하는 핵심 기술 중 하나입니다. 자바(Java)와는 이름만 비슷할 뿐 완전히 다른 언어입니다.
• 주요 역할:
	• 웹 페이지의 텍스트 변경, 이미지 애니메이션, 버튼 클릭 반응 등 동적 인터랙션을 처리합니다.
	• 쇼핑몰 장바구니 가격 자동 계산, 폼(입력창) 데이터 유효성 검사 등을 수행합니다.
• 사용 범위:
	• 프론트엔드: 브라우저 안에서 동작하며, React, Vue.js 같은 프레임워크가 널리 쓰입니다.
	• 백엔드: Node.js 같은 런타임을 통해 서버, 데이터베이스 연동, API 개발 등 웹 서버 영역으로 확장되었습니다.
• 특징: 동적 타이핑(Dynamic typing), 프로토타입 기반 객체지향, 싱글 스레드 기반의 비동기 처리 등을 지원합니다.
```
