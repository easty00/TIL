#### 싱크, 어웨이트, 프로미스
- 프로미스 형태로 소스코드 작성 

1. 프로미스의 3가지 상태 (States)

프로미스는 생성되어 처리되기까지 다음 중 하나의 상태를 가집니다:
• 대기 (Pending): 비동기 처리가 아직 완료되지 않은 초기 상태
• 이행 (Fulfilled): 비동기 처리가 성공적으로 완료되어 약속을 이행한 상태 (resolve 호출)
• 거부 (Rejected): 비동기 처리가 실패하거나 오류가 발생한 상태 (reject 호출)
• 정착됨 (Settled): 이행되었거나 거부된 상태 (더 이상 상태가 바뀌지 않음)

2.new Promise() 생성자는 실행 함수(executor)를 인자로 받으며, 이 함수는 resolve와 reject resolve와 reject 두 가지 콜백을 가집니다
```
const myPromise = new Promise((resolve, reject) => {
  const success = true; // 비동기 작업 가정
  
  if (success) {
    resolve("성공 결과 값"); // Fulfilled 상태로 전환
  } else {
    reject(new Error("실패 이유")); // Rejected 상태로 전환
  }
});

```

1. 핵심 키워드 개념

• async (Asynchronous)
	• 함수 선언 앞에 붙이는 키워드입니다.
	• async가 붙은 함수는 항상 프로미스(Promise)를 반환합니다.
	• 함수 내부에서 프로미스가 아닌 일반 값을 반환하더라도, 자바스크립트가 자동으로 이행된(fulfilled) 프로미스로 감싸서 반환합니다.
• await (Wait)
	• 반드시 async 함수 내부에서만 사용할 수 있는 키워드입니다.
	• 프로미스 앞에 await를 붙이면, 해당 프로미스가 처리(settled)될 때까지 함수의 실행을 잠시 중단하고 기다립니다.
	• 프로미스가 성공적으로 이행되면 그 결과 값을 그대로 반환받아 변수에 할당할 수 있습니다.

2. 기본 문법 비교

기존 Promise .then() 방식:

```
function fetchUser() {
  return fetch('https://example.com')
    .then(response => response.json())
    .then(user => user.name);
}

```

async / await 적용 방식:
```
async function fetchUser() {
  // fetch가 완료될 때까지 기다렸다가 response 변수에 담음
  const response = await fetch('https://example.com');
  
  // JSON 파싱이 완료될 때까지 기다림
  const user = await response.json();
  
  return user.name;
}

```
